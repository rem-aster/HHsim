HHsim — графический симулятор Ходжкина–Хаксли (русская версия)

HHsim работает в свободной программе GNU Octave. MATLAB не нужен.

Установка
1. Перетащите HHsim.app в папку «Программы».
2. Установите GNU Octave. Проще всего через Homebrew (https://brew.sh/ru/):
   откройте Терминал и выполните
       brew install octave
   Если Octave не установлен, HHsim при запуске сам предложит это сделать.
3. Первый запуск: щёлкните по HHsim.app правой кнопкой мыши (или с клавишей
   Control) и выберите «Открыть», затем ещё раз «Открыть» — приложение не
   подписано сертификатом Apple. Если macOS всё равно не даёт его открыть:
   «Системные настройки» → «Конфиденциальность и безопасность» →
   «Всё равно открыть». Либо выполните в Терминале:
       xattr -dr com.apple.quarantine /Applications/HHsim.app

Подробнее: https://github.com/rem-aster/HHsim
