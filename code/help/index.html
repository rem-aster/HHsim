HHsim: графический симулятор Ходжкина–Хаксли

David S. Touretzky, Mark V. Albert, Nathaniel D. Daw, Alok Ladsariya, Mahtiyar Bonakdarpour

HHsim — графическая модель участка возбудимой мембраны нейрона, основанная на уравнениях Ходжкина–Хаксли, с полным доступом к параметрам каналов, мембраны, стимулов и концентрациям ионов. Это учебная программа для курсов нейрофизиологии; её интерфейс осваивается за пару минут.
